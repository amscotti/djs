# v0.11.0 — Node partials batch 1

## Plan

The user asked to stop deferring the "partial" rows and fold them into the
pre-1.0 plan. `docs/COMPAT-BACKLOG.md` now assigns every partial a version.
Batch 1 is this release — cheap, high-value native surfaces that frameworks and
scripts reach for:

- `process.hrtime`/`hrtime.bigint`, `process.uptime`, `process.kill`
- `os.uptime`, `os.loadavg`, `os.networkInterfaces`, `os.userInfo`
- `fs.statfsSync`/`fs.statfs`
- `dgram` broadcast, TTL and multicast-membership options

Batch 2 (v0.11.1): child `timeout`/`maxBuffer`/AbortSignal, net IPv6 + idle
timeouts, HTTP keep-alive/chunked requests/HEAD/100-continue/deadlines, fs
stream chunking, `fs.opendir`.
Batch 3 (v0.12.1): `fs.watch`, `dns.resolve*`, `vm`, `perf_hooks`, WebSocket
client, Web Streams interop, dgram buffer options/IPv6.

## Architecture

- New native functions follow the existing `__djs.<module>` pattern and are
  wrapped by the JS facade. **That dual surface is the main hazard**: natives
  are invisible until the facade exposes them. `os.uptime` and friends were
  installed natively but `require('os')` still returned `undefined` until the
  `g.os` object was extended; `node_partials` now asserts the public surface.
- `process.kill` parses names or numbers, gates on `sys:kill`, returns `true`
  on `EPERM` (Node semantics) and throws `ESRCH` otherwise.
- `os.networkInterfaces` uses `getifaddrs`; IPv4/IPv6 addresses are rendered
  with `inet_ntop`, netmasks counted into CIDR. MAC is a placeholder because
  `AF_PACKET` is not handled.
- `fs.statfs` uses `statvfs`; the async form is a microtask over the sync call
  (no blocking I/O is involved beyond the syscall).
- dgram option constants (`IP_TTL`, `IP_MULTICAST_TTL`, `IP_ADD/DROP_MEMBERSHIP`,
  `IPPROTO_IP`) are not exported by druntime and are defined for Linux. This is
  a portability seam for v1.0.
- Counters and conversions use `toInt32`/`setIndex`, matching neighbouring code.

## Application review

| # | Severity | Finding | Reproduction | Fix |
|---|---|---|---|---|
| 1 | high | native `os` additions were not reachable from `require('os')` because the prelude facade lists each function | `typeof os.uptime` → undefined after the native build | facade extended; `node_partials` asserts the public API, not just `__djs` |
