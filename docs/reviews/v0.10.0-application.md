# v0.10.0 application review

Review of the server/UDP/readline change set against the whole runtime.

| # | Severity | Finding | Reproduction | Impact | Disposition |
|---|---|---|---|---|---|
| 1 | critical | `server.close()` passed a static `Listener*` to `pollCloseCb`, which treats the handle data as a heap `CloseCtx` and frees it | any `net.createServer().listen(...).close()` aborted with `free(): invalid pointer` | crash after a normal close; static memory corruption | dedicated `closeListenerHandle` with a heap `CloseCtx`; `net_server` closes cleanly under ASan |
| 2 | high | socket ids were slot indexes; a disconnected client handle could address a later accepted server socket in the same slot | close a client, accept a connection, call `write` on the old id | cross-connection data injection/read | generation-tagged ids and `findSock` for every socket operation |
| 3 | high | the HTTP client half-closed after sending (`socket.end(raw)`); a same-process server saw EOF and closed before responding | `http.get` against `http.createServer` → `malformed HTTP response` | every in-process HTTP test failed; also affects servers that respond slowly | client writes without `end()`; `Connection: close` ends the exchange |
| 4 | medium | a handler passed to `http.createServer` ran twice (constructor callback + `request` emit) | first response wins, second write errors | double side effects | handler registered as a `request` listener; `_accept` only emits |
| 5 | medium | `dgram.send(..., "localhost")` failed because `inet_pton` accepts literals only | `send("x", port, "localhost")` → TypeError | common host form unusable | JS maps `localhost` to `127.0.0.1` for send and bind |
| 6 | low | `net.Server` listen callback fired through `queueMicrotask`, so `address()` is valid only inside/after it | `s.listen(0); s.address()` → null | ordering surprise, matches Node closely enough | documented by test ordering |
| 7 | low | no HTTP keep-alive, chunked request bodies, `Expect: 100-continue`, trailers or WebSocket upgrade | — | limited conformance | COMPAT lists them; not regressions |
| 8 | low | no server-side request deadline (slowloris) | a client that sends one byte per second holds a socket | 128-slot cap bounds it; a full table rejects new connections | documented residual for v1.0 hardening |
| 9 | high (release) | `djsVersion` stayed at `v0.8.0` through v0.9.0/v0.9.1, so `scripts/package.sh` produced a `djs-v0.8.0` tarball containing v0.10 code | `./djs --version` before the fix | mislabelled release artifacts | bumped to `v0.10.0`; added `VERSION` + `scripts/check-version.sh` as a gate step; the v0.8.0 tarball was rebuilt from its tag and its original sha256 restored |

## Test coverage added

- `tests/js/net_server.js`: real listener, accept, request/response over TCP,
  clean close (exercises the invalid-free path).
- `tests/js/http_server.js`: GET with a custom header, POST echo with status
  201 and content-type, 404, chunked-free `content-length` response, close.
- `tests/js/dgram.js`: two bound IPv4 sockets, `message` on both sides with
  `rinfo.address`/`rinfo.port`, clean close.
- `tests/js/worker_threads.js`: main-thread stub and the explicit
  `ERR_WORKER_THREADS_UNSUPPORTED` error.
- `tests/js/fixtures/readline.js` + integration pipe: LF and CRLF handling and
  `close` at EOF.
- `gate-permissions.sh`: `listen-denied`, `listen-allowed` and
  `dgram-bind-denied` (the new inbound/UDP capability boundary).

## Verification

- `scripts/gate.sh` **10/10** (abi, no-phase-refs, build, unittest,
  permissions 42, integration 97, sanitize 60 fixtures, net, diff 11, soak).
- ASan/LSan clean on `net_server`, `http_server`, `dgram`, `worker_threads`.
- No new dependency; the server uses the existing socket/poll layer.

## Residual gaps

- HTTPS server (certificate/key options, ALPN) — post-1.0, see the v0.10.0
  plan review.
- HTTP/1.1 keep-alive and chunked request bodies; no HTTP/2.
- IPv4 only for listeners and UDP.
- No per-connection timeouts or graceful drain on `server.close()`.
