# v0.14.3 — prelude split

## Plan

`js/prelude.js` had grown to 5,872 lines and 265 KB in one IIFE. Split it into
ordered modules that the compiler concatenates back into the same source, with
no behavioural change.

## Layout

| File | Contents |
|---|---|
| `js/prelude/01-core.js` | process, path, stack introspection, Buffer |
| `js/prelude/02-fs.js` | fs and fs/promises |
| `js/prelude/03-streams.js` | events, streams, url |
| `js/prelude/04-platform.js` | util, timers/promises, abort, structuredClone, fs streams, child_process, net basics, DNS |
| `js/prelude/05-http.js` | HTTP client and server |
| `js/prelude/06-modules.js` | readline, assert, module loader glue, stream/promises, crypto/zlib |
| `js/prelude/07-net.js` | TLS, WebSocket, HTTP/2, WebCrypto, global exports |

`src/djs/runtime.d` builds `preludeSource` by concatenating the seven
`import("prelude/…")` strings; the bytes are identical to the old monolith.

## Application review

| # | Severity | Finding | Verification |
|---|---|---|---|
| 1 | high | concatenation order changes initialization | rejoined files byte-identical to the saved original (`265493` bytes) |
| 2 | high | string imports under `js/` subdirectory may not resolve | `dub build` succeeds; smoke of Buffer, WebCrypto, ws |
| 3 | medium | edits to one module silently not rebuilt | build always concatenates all seven; gate rebuilds first |

## Verification

- byte-for-byte rejoin check before deleting the monolith
- `buffer_full`, `webcrypto`, `websocket`, `http2`, `ws` compat smoke
- full gate 14/14

## Residual

The split is mechanical by section, not by dependency: all files still share
one IIFE scope and load order matters. A later pass could give modules explicit
dependencies, but that is a larger redesign than this cleanup.
