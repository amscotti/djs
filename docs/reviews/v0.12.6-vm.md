# v0.12.6 — vm contexts

## Plan

`vm` was the last blocker before Web Streams. It is implemented honestly: a new
QuickJS context on the same runtime, not `eval` wearing a sandbox hat.

Delivered: `vm.runInThisContext`, `vm.runInNewContext`, `vm.runInContext`,
`vm.createContext`, `vm.isContext`, `vm.Script`.

## Architecture

- `runInNewContext` calls `JS_NewContext(rt.rt)`; the new context has only
  QuickJS intrinsics — no `require`, `process`, `fs`, timers or global djs
  installs.
- The sandbox crosses as JSON: JS stringifies it, native `JS_ParseJSON` builds
  an object in the new context, and the script runs inside
  `(function(s){with(s){return eval(code)}})(sandbox)`.
- The result crosses back as JSON (`JS_JSONStringify`); `undefined` stays
  undefined, unserializable values fail with `ERR_VM_RESULT`.
- Exceptions from the new context are converted to an `ERR_VM_SCRIPT` error on
  the caller side with the original message.
- `runInThisContext` uses `JS_Eval` in global scope and propagates original
  exceptions untouched.

## Application review

| # | Severity | Finding | Reproduction | Fix |
|---|---|---|---|---|
| 1 | high | a shared eval would not isolate `process`/`require` | `runInNewContext("typeof process")` | real `JS_NewContext` per call |
| 2 | high | returning JSValues across contexts would be invalid after `JS_FreeContext` | design | JSON boundary before freeing |
| 3 | medium | sandbox mutation would silently affect the caller if shared | design | JSON copy, mutations dropped; documented |
| 4 | low | functions/cycles in results cannot cross | `runInNewContext("({f(){}})")` | `ERR_VM_RESULT` with a clear message |
| 5 | low | `with` requires sloppy mode; `"use strict"` code still evaluates inside eval | `vm` semantics | documented; strict directives apply to the evaluated code, not the wrapper |

## Verification

`tests/js/vm_basic.js` + golden: `1+2` → 3; sandbox `a*5` → 10;
`typeof process` → `undefined`; `new vm.Script("({x:a+1})")` → `{"x":5}`;
`throw` keeps message; `return` outside function → `ERR_VM_SCRIPT`.

Full gate 12/12 (sanitize includes `vm_basic`).

## Residual

No `microtaskMode`, `breakOnSigint`, code cache or `importModuleDynamically`.
Web Streams moved to v0.12.7.
