# v0.16.0 — core API long tail

## Implemented

- `process.ppid`, `process.title` (stored; does not rename the OS process)
- `crypto.getRandomValues(TypedArray)` (65536-byte cap)
- `AbortSignal.any(signals)`
- `util.parseArgs` (string/boolean options, short flags, multiples, defaults,
  positionals, strict unknown-option errors)
- `util.styleText` (ANSI bold/dim/italic/underline/colors)
- `url.fileURLToPath` / `url.pathToFileURL`
- `fs.globSync` / `fs.glob` (`*`, `**`, `?`; callback form)
- `timers` builtin (`setTimeout`/`setInterval`/`setImmediate` + clears)

## Application review

| # | Severity | Finding | Verification |
|---|---|---|---|
| 1 | high | `crypto.getRandomValues` filled the array with zeros | test now asserts a non-zero byte; direct probe prints random bytes |
| 2 | high | `process.ppid` was undefined | numeric ppid > 0 |
| 3 | high | `fs.glob` was missing | glob returns 3 PEM fixtures; callback form returns 3 keys |
| 4 | medium | `util.parseArgs` missing | `--name djs -v file.js` → `djs true file.js` |
| 5 | medium | URL path conversion missing | round-trips `file:` → absolute path |
| 6 | low | `timers` could not be required | `require("timers").setImmediate` is a function |

The zero-filled `getRandomValues` bug was introduced by reading the native
random buffer directly instead of wrapping it in a `Buffer`; the probe caught
it before release.

## Verification

`tests/js/api_long_tail.js` golden; full gate 14/14.

## Residual

- `process.title` does not call `prctl`/`setproctitle`; it only changes the JS
  value.
- `fs.glob` is a simple walker: no `withFileTypes`, `exclude`, `dot`, or
  symlink-follow semantics; patterns are POSIX-style.
- `util.parseArgs` has no `tokens` output and limited negative-number handling.
- `AbortSignal.any` subscribes without unsubscribing (signals are short-lived).
- `timers` has no `promises` on the same object (use `timers/promises`).
