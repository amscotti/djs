# v0.13.0 — WebSocket

## Plan

The v0.13.0 row originally said HTTP/2 plus WebSocket. WebSocket is delivered
here in full (client and server); HTTP/2 moves to **v0.13.1** and
`worker_threads` to **v0.13.2**. Splitting is deliberate: HTTP/2 needs a frame
codec and HPACK, which would have delayed a working WebSocket by another
release.

## Architecture

- `djs:ws` exports `WebSocket` and `WebSocketServer`.
- The server is a raw `net.Server`: it parses the request headers, validates
  `Sec-WebSocket-Key`, writes `101` with the SHA-1 accept value and then hands
  the socket to a connection wrapper.
- `WsConnection` decodes masked client frames, emits `message` (string for text,
  Buffer for binary), answers pings and completes the close handshake.
- The client performs the handshake over `net.connect`, verifies the accept
  header, then masks outgoing frames and decodes unmasked server frames.
- Frame encoding supports 7-bit, 16-bit and 64-bit lengths; decoding is
  FIN-only (fragmented messages are not reassembled yet).

## Application review

| # | Severity | Finding | Reproduction | Fix |
|---|---|---|---|---|
| 1 | high | `Buffer.indexOf("\r\n\r\n")` returns -1 — the prelude Buffer has no string search | handshake never completed | `wsFind` byte matcher |
| 2 | high | `writeUInt16BE`/`readUInt16BE`/`readUInt32BE`/`writeUInt32BE` are missing | frame codec threw | local `wsU16`/`wsW16`/`wsU32`/`wsW32` helpers |
| 3 | medium | a test timer printed "timeout" after success and kept the loop alive | gate noise | `received` flag + `unref()` |
| 4 | low | no fragmentation, wss, permessage-deflate, subprotocols | design | documented |
| 5 | low | server upgrade is not the `http.Server` event | design | documented; HTTP/2 upgrade is v0.13.1 |

## Verification

to `/chat`, sends `hi`, receives `echo:hi`, close code 1000.

Full gate 12/12 (sanitize includes `websocket`).

## Residual

Fragmented frames, `wss://`, subprotocols, `permessage-deflate`, HTTP upgrade
integration, and >2 GiB payloads.
