# v0.12.4 — dns.resolve A/AAAA

## Plan

Add address record resolution on top of the existing getaddrinfo request path.
Only A and AAAA are supported; MX/TXT/SRV/CNAME need `res_query` parsing and
move to the v0.12.5 batch with `vm`, `fs.opendir` and Web Streams.

## Architecture

- `DnsReq` gained a `resolve` mode (0 lookup/connect, 4 A, 6 AAAA) and the
  getaddrinfo hints select the family for record queries.
- The DNS callback branches before the lookup/connect paths: it walks results,
  formats each address with `inet_ntop`, drops duplicates (getaddrinfo can
  repeat an address), builds a JS array and calls back `(null, list)`.
- Empty result sets fail with the existing ENOTFOUND-style error path.
- JS `resolve4`, `resolve6` and `resolve(host, type)` share the same native
  entry; unsupported types produce `ENOTSUP` asynchronously.
