# v0.14.1 — real-library compatibility (`ws`, `jose`)

## Plan

Stop testing only our own goldens: install `ws` and `jose` under
`tests/compat/` and run them on every gate. They exercise the HTTP upgrade
handoff, socket duplex behaviour, frames, `crypto.subtle`, `KeyObject` and the
callback forms of `crypto.sign`/`verify`.

## Findings and fixes

| # | Severity | Finding | Reproduction | Fix |
|---|---|---|---|---|
| 1 | high | client `http.request` never emitted `upgrade`; 101 arrived as a normal response | `new WebSocket(...)` → `unexpected-response 101` | parser detects 101, emits `upgrade(res, socket, head)` and stops |
| 2 | high | `crypto.randomFillSync` missing | `ws` sender `not a function` | implemented sync + callback `randomFill` |
| 3 | high | `crypto.createSecretKey` / `KeyObject.from` missing | `jose` sign `TypeError` | secret KeyObjects, CryptoKey→KeyObject conversion |
| 4 | high | `crypto.sign`/`verify` ignored callbacks, so `util.promisify` hung | RS256 sign never settled | optional callback, microtask delivery |
| 5 | high | `KeyObject.asymmetricKeyType`/`asymmetricKeyDetails` absent | jose `asymmetricKeyType must be rsa` | detect RSA/EC/Ed25519 OIDs; parse RSA modulus length |
| 6 | medium | socket lacked `_readableState`/`_writableState`; ws crashed on close | `endEmitted of undefined` | state shims on Socket/Writable, updated on end/finish |
| 7 | medium | `socket.cork()`/`uncork()` missing | ws `sendFrame` `not a function` | no-op corking |
| 8 | medium | `createPrivateKey({key: DER, format:'der'})` stored a Buffer | `modulusLength` undefined | DER→PEM conversion, label-aware |
| 9 | low | `util.types.isKeyObject` missing | jose type check threw | added |

## Verification

`scripts/gate-compat.sh` is now gate step 14:

- `ws_smoke.js`: real `WebSocketServer` + `WebSocket`, handshake, masked client
  frame, echo, clean close → `ws echo:hello`
- `jose_smoke.js`: `SignJWT`/`jwtVerify` HS256 and RS256 (PKCS#8/SPKI import) →
  `hs256 user-1 3`, `rs256 admin 3`

Full gate 14/14.

## Residual

`ws` pause/backpressure still relies on a state shim, not a true Duplex; cork is
a no-op; no permessage-deflate coverage. `jose` ECDSA/JWK export paths are not
in this smoke set.
